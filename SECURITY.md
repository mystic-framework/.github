# Security

This section outlines the security measures and best practices implemented in our framework to ensure the safety and integrity of
your applications.

## Reporting Vulnerabilities

Please report any security vulnerabilities you discover in our framework to the maintainer via email at
[thedevmystic@gmail.com](mailto:thedevmystic@gmail.com). We take all reports seriously and will respond promptly to address any issues.

Please do not report security vulnerabilities in public forums or issue trackers, as this may expose your application to potential risks.
Instead, use the provided email address for confidential communication.

## Response Process

You can expect the following response process after reporting a vulnerability:
- We will acknowledge receipt of your report within 1-3 days.
- We will assess the severity of the vulnerability and provide an estimated timeline for resolution.
- We will work on a fix and release a patch as soon as possible.

## Scope

What counts as in-scope for security vulnerability reports:
- Vulnerabilities in the framework's core codebase.
- Vulnerabilities in any official plugins.
- Vulnerabilities in any tools or utilities provided by the framework.

What counts as out-of-scope for security vulnerability reports:
- Vulnerabilities in third-party libraries or dependencies. (Please report these to the respective maintainers of those libraries.)
- Vulnerabilities in your own application code or configuration.
- Vulnerabilities in other frameworks or platforms not maintained by us.
- Typos in documentation or non-security related issues.

## Disclosure Policy

We follow a responsible disclosure policy. Once a vulnerability is reported, we will work with the reporter to ensure that the issue
is resolved before making any public announcements. We will credit the reporter in our release notes if they wish to be acknowledged.

**Please keep it private until resolved.**
