# Support

This page provides information on how to get help and support for any issues or questions you may have while using the framework.

## Before You Ask for Support

Check the following resources before reaching out for support:
- Documentation: Make sure to read the [official documentation](https://mystic-framework.github.io/docs/) thoroughly. Many common questions and issues are addressed there.
- Compatibility: Ensure that you are using the correct version of the framework and that your environment meets the necessary requirements. Visit: [Compatibility](https://mystic-framework.github.io/docs/compatibility/).
- FAQs: Check the [Frequently Asked Questions](https://mystic-framework.github.io/docs/faqs/) section for answers to common queries.

## Where to go?

You can reach out for different types of support depending on your needs:
- Bug / Broken behavior: If you encounter a bug or broken behavior, please report it on specific modules' GitHub issue page. Follow the practices outlined in the [Contributing Guide](https://mystic-framework.github.io/docs/contributing) to ensure your report is clear and actionable.
- "How do I" / Usage questions: For questions about how to use the framework or specific features, you can ask on the [GitHub Discussions](https://github.com/orgs/mystic-framework/discussions/) page. This is a great place to get help from the community and the maintainers.
- Security issues: If you discover a security vulnerability, please report it privately to the maintainers. You can find the contact information in the [Security Policy](https://mystic-framework.github.io/docs/security).

## Response Time

This project is maintained by volunteers (possibly will remain solo-maintained), and response times may vary. While we strive to respond as
quickly as possible, please be patient and allow some time for maintainers to review and respond to your inquiries.

## Found answer? Share it!

If you found an answer to your question or resolved your issue, consider sharing it with the community. You can contribute to the
documentation, answer questions on GitHub Discussions, or share your solution in relevant forums. Your contributions help others who may
face similar challenges in the future.
