## About

Mystic Framework is a modern, performance-oriented framework that refuses to sacrifice elegance and readability code. It means
that it tries to strike a balance where the code is as performant as it gets while still being clear and readable.

It is written in C++23 and its architecture is [C++ Module](en.cppreference.com/cpp/language/modules)-heavy. The entire framework
itself is modular meaning you can choose what you want to include in your project easily. Each module is focused on one-thing and
tries to do it perfectly.

If you want to look more into our design philosophy then you can view these resources:
1. [Design Philosophy](https://mystic-framework.github.io/docs/design-philosophy/)
2. [Blog Post](https://mystic-framework.github.io/blog/posts/mystic-framework-website-is-now-live/)
